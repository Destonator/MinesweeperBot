# Destons Minesweeper Bot #

An application that plays Google Minesweeper. This software only works on MacOS. If you download just the bot.py, it should work on any OS when run from VS Code or the terminal. 
## [Download for Mac](https://drive.google.com/uc?export=download&id=1kAwLrWUZECk-dVRI3iG8q2wWFjxR2o0x) ##

This app works by taking a screenshot of the Minesweeper playing area, and it then samples the color from the center of the tile, and from the color, it can determine the number value the tile holds. The board is then stored, and through a series of algorithms, the bot knows which tiles are safe and which contain mines. The bot then clicks the safe tiles and repeats until the game has been won.
